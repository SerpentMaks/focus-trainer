# Фокус

Тренажёр внимания, реакции и рабочей памяти для телефона. Работает офлайн, ставится на главный экран как обычное приложение. Результаты хранятся только на устройстве.

## Упражнения

| Упражнение | Что тренирует | На чём основано |
|---|---|---|
| Реакция | Простая скорость реакции | Классический тест времени реакции |
| Стоп-сигнал | Торможение импульсивных нажатий | Go/No-Go |
| Периферия | Скорость восприятия и ширина поля внимания | Тренировка UFOV из исследования ACTIVE: эффект на скорость обработки держался до 10 лет |
| Стрелки | Устойчивость к отвлекающим помехам | Задача Эриксена (flanker) |
| Цвет слова | Контроль автоматических реакций | Тест Струпа |
| Таблица Шульте | Распределение внимания, поиск взглядом | Таблицы Шульте |
| N назад | Рабочая память | N-back с подстройкой уровня |
| Квадраты | Зрительно-пространственная память | Блоки Корси |
| Счёт дыханий | Удержание внимания, меньше блуждания мыслей | Breath counting task (Levinson и др., 2014) |

Честно о пользе: такие тренировки лучше всего прокачивают сами упражнения и близкие к ним навыки. Перенос на «общий интеллект» в исследованиях небольшой. Самые убедительные данные — у тренировки «Периферия» (скорость восприятия) и у счёта дыханий (меньше блуждания мыслей).

## Как выложить на GitHub Pages

1. Создай на GitHub пустой публичный репозиторий, например `focus-trainer`.
2. Загрузи в него все файлы из архива (кнопка «uploading an existing file», перетащи содержимое папки целиком, вместе с папками `css`, `js`, `icons`).
3. В репозитории открой Settings → Pages. В разделе Build and deployment выбери Source: «Deploy from a branch», ветка `main`, папка `/ (root)`, нажми Save.
4. Через минуту-две сайт откроется по адресу `https://<ник>.github.io/focus-trainer/`.

## Как установить на iPhone

1. Открой адрес в Safari.
2. Кнопка «Поделиться» → «На экран Домой».
3. Запускай с иконки — так приложение открывается без панелей браузера и работает без интернета.

На Android: Chrome → меню → «Добавить на главный экран» или «Установить приложение».

## Обновление

После изменения файлов подними `VERSION` в `sw.js` (например, `focus-v1.0.1`), иначе телефон может показывать старую версию из кэша. Если всё равно старая — закрой приложение и открой снова.

Перед удалением иконки с главного экрана iPhone сохрани копию данных: Статистика → «Сохранить копию в файл». Удаление иконки может стереть результаты.
